# מלאגה 2026 — אפליקציית הטיול המשפחתי

אפליקציית רשת סטטית, בעברית ומותאמת לטלפון, לטיול של שתי משפחות במלאגה ובקוסטה דל סול בתאריכים 4–14 באוגוסט 2026.

## מה יש באפליקציה

- מסך בית עם ספירה לאחור והיום הנוכחי.
- תוכנית יומית מלאה ל־11 ימים, עם ימי חוף, מלאגה, בנאלמדנה, מיחאס ומרבייה.
- פרטי טיסות ארקיע IZ261 ו־IZ262.
- שתי לינות מאושרות בטורמולינוס, שני חדרים בכל מלון.
- ניווט ישיר, תחזית לפי מיקום ומספרי חירום.
- תזכורת פתוחה לסגירת תחבורה שמתאימה ל־8 נוסעים ולמזוודות.
- מצב עריכה מקומי, ייבוא וייצוא של נתוני הטיול.
- PWA לשמירת מעטפת האפליקציה גם בקליטה חלשה.

## הרצה מקומית

```bash
python3 -m http.server 8080
```

לאחר מכן פותחים `http://localhost:8080`.

## פרטיות

מסמכי המקור שצורפו כוללים שמות נוסעים, מספרי הזמנות ומספרי כרטיסים, ולכן אינם מועתקים לאתר הציבורי. באפליקציה נשמר רק תקציר שימושי ומצונזר.

## עריכת התכנון

`trip-data.js` הוא מקור האמת. אפשר גם להפעיל מצב עריכה באתר; השינויים נשמרים ב־`localStorage` של אותו דפדפן, וניתן לייצא אותם לקובץ `malaga-trip-data.json`.
